# Amazon FBM 盈亏管理系统

单文件离线经营管理工具，包含产品库、订单管理、费用中心、退款/售后、经营总览、月度损益、SKU 利润分析及完整数据备份/恢复。

## 使用方法

打开 `index.html` 即可使用。经营数据保存在打开该网页的浏览器 IndexedDB 中，不会随源代码上传到 GitHub。

## 数据安全

请定期在系统左下角点击“导出全部数据”，将生成的 JSON 备份保存到网盘。换电脑或清理浏览器数据后，可从“数据备份与恢复”导入 JSON。

## 核心计算口径

产品贡献利润 = 美元销售额 × 锁定汇率 × 0.75 − 采购成本 − 运费 − 订单直接成本。

运营抽成、固定费用、其他费用和售后损失仅在月度经营层面扣除。
